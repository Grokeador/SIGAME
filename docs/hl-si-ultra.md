## What the preset does
Writes the Engine.ini block Hogwarts Legacy players share on Steam into the game's own file, with the texture pool set to half of YOUR video memory instead of someone else's number, then locks the file read-only because players report the game removes added lines. Your other lines stay. UNDO restores your file exactly. Measure with your own FPS counter.

## How do I apply it?
1. Download SIGAME: https://github.com/Grokeador/SIGAME (Code, Download ZIP, extract).
2. Double-click `SI-GAME-AUTO.bat`.
3. SI PRESETS, Check for new presets, Yes.
4. Close the game, pick **SI ULTRA (Hogwarts Legacy (PC))**, APPLY, Yes. APPLY again and Yes = Undo.
